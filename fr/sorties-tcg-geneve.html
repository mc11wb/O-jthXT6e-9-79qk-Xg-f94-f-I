Comment lire ce calendrier

Nous sommes approvisionnés par les distributeurs officiels : un set est en rail le jour de sa sortie, dans les huit machines. Il part vite, les sets les plus attendus se vident en quarante-huit heures. Le seul moyen fiable de savoir s'il en reste est la page Stock Live, qui lit l'inventaire directement dans les machines connectées.

Les dates marquées à confirmer sont des fenêtres annoncées par l'éditeur sans jour fixé ; nous les mettons à jour dès qu'elles sont officielles.

Questions fréquentes

Quand sort le prochain set Pokémon ?
Méga-Évolution : Delta Reign sort le 6 novembre 2026, avec Méga-Rayquaza ex en tête d'affiche. C'est le dernier set Méga-Évolution de l'année. Le set des 30 ans, 30th Celebration, est sorti le 16 septembre.
Quand sort One Piece OP-18 ?
En novembre 2026. Bandai a confirmé le mois mais pas le jour ; les distributeurs tablent sur le 20 novembre. L'extra booster EB-05 arrive avant, fin octobre.
Quand sort Riftbound Radiance ?
Le 23 octobre 2026, après une semaine de Pre-Rift du 16 au 22. 180 cartes dont 66 Showcase. Le set suivant, Legacy, est daté du 29 janvier 2027.
Un set est-il disponible dans vos machines le jour de sa sortie ?
Oui. Nous sommes approvisionnés par les distributeurs officiels et les nouveautés sont mises en rail le jour de leur sortie. La page Stock Live indique en direct ce qui est en machine.
Comment être prévenu d'une arrivée ?
Le bouton de demande sur la page des licences enregistre votre intérêt pour une licence. Les demandes orientent les allocations et le réassort.
